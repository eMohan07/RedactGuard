🔗 How Name Variants are Linked (Coreference)

EntityLinker parses names into constituent honorifics (Dr., Mr.), first/middle/last tokens, and initials. It links initials (e.g. "Dr. R Sharma", "R. Sharma") and constituent bare tokens ("Richa", "Sharma") to the full entity ("Richa Sharma") into a single unified canonical tag (e.g. [NAME_1]), while flagging shared surnames between multiple people for human safety.

🔍 How Summary is Checked Against Leaking Information

1. Redact-First Pipeline: The summarizer accepts strictly already-redacted text with canonical placeholders (e.g. [NAME_1]); it never receives raw PII.
2. Quasi-Identifier Neutralization: Pre-synthesis rules generalize indirect combinations (e.g. "CFO of a Pune-based firm") into generalized roles.
3. Multi-Engine Leak Audit: Re-scans generated summary against all removed approved spans, constituent name tokens, digit sequences, and autonomous PII rules before export.
